Zaid Personal Automation

Zaid Personal Automation is a private, self-hosted automation system operated by Zaid Farah. It connects the owner's Google account to local n8n workflows for tasks such as managing selected Gmail events and uploading original YouTube Shorts to the owner's channel.

How Google data is used

Google account access is used only to perform actions explicitly configured by the owner. YouTube access is used to identify the selected channel and upload and verify videos. Gmail access, when enabled in a separate workflow, is used only for that owner's configured email automation.

The application is not offered as a public service, does not sell Google user data, and does not use Google user data for advertising.
